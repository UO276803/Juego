# Misión: Sacarte una Sonrisa 🩺❤️

Mini-juego de plataformas hecho con HTML, CSS y JavaScript puro.

## Cómo abrirlo

1. Abre esta carpeta en VS Code.
2. Abre `index.html`.
3. Puedes abrirlo directamente en el navegador.
4. Para probarlo como una web, también puedes instalar la extensión **Live Server** de VS Code y pulsar "Go Live".

## Controles

### Móvil
- ◀ mover izquierda
- ▶ mover derecha
- ⬆️ saltar

### Ordenador
- A / ← izquierda
- D / → derecha
- W / ↑ / espacio saltar

## Personalizar el mensaje

En `index.html`, busca:

```html
<div class="personal-note">
```

y cambia el texto por algo que sea vuestro.

También puedes cambiar el título, las frases y los emojis directamente en `index.html`.

## Compartir por WhatsApp

Para que ella pueda jugar desde su móvil, lo ideal es subir esta carpeta a un servicio de hosting estático (por ejemplo, GitHub Pages, Netlify o Vercel) y mandarle el enlace.

El proyecto no necesita servidor ni base de datos.
